# AI-Assisted Debugging Assessments

This repository contains a collection of software engineering test environments designed to simulate the debugging constraints of big tech online assessments. 

The primary objective is to practice targeted AI-assisted problem solving. Rather than feeding an entire problem statement to an AI for a zero-shot solution, these tests evaluate how effectively a developer can strategically guide AI tools to identify, isolate, and fix complex bugs iteratively. Each module challenges you to analyze execution logs, navigate the codebase, and craft precise, constrained prompts to resolve logic flaws, mirroring the real-world workflows required in rigorous technical interviews.
